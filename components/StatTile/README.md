# StatTile

StatTile shows one labelled value: an ALL-CAPS `label` over a big serif value, on a pastel card.

**Provide:** `label` (short, caps are applied for you), `value` (a number or a single word), optional `tone` (default `lilac`).

Stack tiles vertically with `space-4` gaps, toning them `lilac` → `sage` → `peach`. Don't: put sentences in the value, or use more than one tile tone to mean good/bad.
