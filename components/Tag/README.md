# Tag

Tag is a small outlined label for categories, and with `tone="mention"` the inline @mention chip.

**Provide:** `children` (one or two words) and `tone`: `stone` (default), `lilac`, `sage`, `peach`, `periwinkle`, `mint`, `rose`, or `mention`.

Mentions sit inline in text: `<Tag tone="mention">@Assistant</Tag> did Nate change outfits?`. Don't use tags as buttons.
