# Icon

Icon draws Inkline's line icons: a 24px grid, 2px round strokes, `currentColor`.

**Provide:** `name` (play, pause, restart, comment, volume, download, expand, sidebar, check, plus, close, search, more), optional `size` (default 20), `strokeWidth`, and `title` when the icon carries meaning on its own (otherwise it's hidden from screen readers).

Intentional addition: the screenshots show these glyphs in the media bar. Exporting them keeps every other surface consistent.
