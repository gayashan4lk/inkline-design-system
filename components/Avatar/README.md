# Avatar

Avatar is a circular initial for a person or agent, outlined in ink on a pastel fill.

**Provide:** `name` (used for the initial and the accessible label), optional `initial`, `tone` (default `periwinkle`), and `size` (`sm` 24 · `md` 32 · `lg` 44). Without `name` or `initial` the avatar is decorative and hidden from screen readers.

Give each person a stable tone. Reserve `clay` for an assistant or system voice.
